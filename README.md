# 🍅 MyPomodoro

Aplicação web desenvolvida em React que implementa a técnica Pomodoro, auxiliando na organização do tempo e aumento da produtividade. O projeto conta com um cronômetro funcional, controle de ciclos de foco e descanso, persistência de dados e execução do timer em segundo plano, garantindo precisão e boa experiência de uso.

## 🛠 Tecnologias

- **React** com componentes funcionais e Hooks
- **Vite + SWC** para desenvolvimento rápido e moderno
- **Context API + Reducer** para estado global
- **React Router DOM** para navegação entre páginas
- **Web Workers** para execução do timer em segundo plano
- **LocalStorage** para persistência de dados
- **CSS Modules** para estilização modular
- **React Toastify** para notificações

## Como rodar o projeto localmente

#### Pré-requisitos

- **Node.js** (versão 18 ou superior recomendada)
- **npm** (vem junto com o Node.js)

### 🔧 Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/seu-usuario/mypomodoro.git](https://github.com/seu-usuario/mypomodoro.git)

1. **Acesse a pasta do projeto:**
    ```bash
    cd mypomodoro

1. **Instale as dependências:**
    ```bash
    npm install

1. **Execute o servidor de desenvolvimento:**
    ```bash
    npm run dev

1. **Acesse no seu navegador**
    O terminal exibirá o endereço local (geralmente http://localhost:5173).
